Detailed Description

Store data for inputting into functions.

This struct stores values min and max, which are intended to be inputted into functions as arguments. Not exposed in the C wrapper.

Examples
GenerateParagraph.cpp, GenerateParagraphs.cpp, GenerateSentence.cpp, GenerateSentenceFragment.cpp, and GenerateSentences.cpp.
