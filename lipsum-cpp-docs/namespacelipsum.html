Generate a random paragraph.

This function generates a random paragraph starting with a tab character and ending in a line break, with each sentence separated by a space.

Returns
std::string The random paragraph.
Parameters

wordThe minimum and maximum possible number of words in a sentence fragment. By default 4 to 9.
