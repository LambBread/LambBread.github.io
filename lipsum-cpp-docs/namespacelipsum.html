Generate a random paragraph.

This function generates a random paragraph starting with a tab character and ending in a line break, with each sentence separated by a space.

Returns
std::string Returns the random paragraph.
Parameters
sentThe minimum and maximum possible number of sentences in the paragraph. By default 5 to 8.
fragThe minimum and maximum possible number of sentence fragments in a sentence. By default 1 to 3.
wordThe minimum and maximum possible number of words in a sentence fragment. By default 4 to 9.
useLipsumWhether the default "Lorem ipsum..." text should start the paragraph. By default set to true.

Parameters
paraCountThe number of paragraphs. By default set to 5.

sentThe minimum and maximum total number of sentences in a paragraph. By default 5 to 8.
useLipsumWhether the default "Lorem ipsum..." text should start the first paragraph. By default set to true.
