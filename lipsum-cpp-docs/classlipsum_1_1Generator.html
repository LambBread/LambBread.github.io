Detailed Description

OOP layer over lipsum-cpp.

Since
0.2.0

This provides a more user-friendly object-oriented layer over lipsum-cpp.

Examples
Advanced.cpp, Generator.cpp, GeneratorFormats.cpp, Markdown.cpp, Misc.cpp, and Source.cpp.
