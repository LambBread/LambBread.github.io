Detailed Description

OOP layer over lipsum-cpp.

This provides a more user-friendly object-oriented layer over lipsum-cpp. It uses mainly default arguments. It is not exposed in the C wrapper. Unlike most of the codebase which uses PascalCase, the functions in this class use snake_case.
