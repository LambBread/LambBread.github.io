Generate a random paragraph.

This function generates a random paragraph starting with a tab character and ending in a line break, with each sentence separated by a space.

Returns
std::string Returns the random paragraph.
Parameters
minSentMinimum number of sentences in the paragraph. By default set to 5.
maxSentMaximum number of sentences in the paragraph. By default set to 8.
minWordMinimum number of words in each sentence. By default set to 4.
maxWordMaximum number of words in each sentence. By default set to 12.
useLipsumWhether the default "Lorem ipsum..." text should start the paragraph. By default set to true.
ratioHow large the random number generated between minWord and maxWord should be compared to maxWord before a comma is added to a sentence. By default set to 0.75.

Generate multiple random sentences at once.

Generate multiple random sentences separated with spaces. Does not add a tab character before the sentences nor a line break after.

Returns
std::string Returns the random sentences.
Parameters
sentCountThe number of sentences. By default set to 6.
minWordThe minimum number of words per sentence. By default set to 4.
maxWordThe maximum number of words per sentence. By default set to 12.
useLipsumWhether the default "Lorem ipsum..." sentence should be the first sentence. By default set to true.
ratioHow large the random number generated between minWord and maxWord should be compared to maxWord before a comma is added to a sentence. By default set to 0.75.
